# iqrcode-learn

Language-neutral terminal animation of QR Code construction, step by step:
segmentation, encoding, Reed-Solomon, interleaving, masking and output.

Built on the `trace` feature of
[`iqrcode-core`](https://crates.io/crates/iqrcode-core).

```bash
cargo install iqrcode-learn
iqrcode-learn "HELLO WORLD"
```

Part of the [iqrcode workspace](https://github.com/InfinityLib/infinity-qrcode).
